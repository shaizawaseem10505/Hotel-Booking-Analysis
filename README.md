# Hotel Booking Analysis

## Project Overview
This project focuses on analyzing hotel booking data to understand booking patterns, cancellation trends, customer behavior, and differences between City Hotels and Resort Hotels.

The analysis aims to extract useful business insights that can help hotels improve booking management and make better decisions.

## Project Objectives
- Analyze hotel booking trends.
- Compare City Hotels and Resort Hotels.
- Study booking cancellations.
- Explore market segments and customer behavior.
- Identify seasonal booking patterns.
- Present insights through visualizations and SQL queries.

## Tools & Technologies
- **Microsoft Excel** – Data analysis, PivotTables, charts, and dashboard.
- **SQL** – Data querying and analysis.
- **GitHub** – Project documentation and portfolio.

## Dataset
- **Dataset:** Hotel Booking Demand
- **Source:** Kaggle
- **Coverage:** City and Resort Hotels in Portugal.
